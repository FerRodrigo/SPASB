# SPASB - Sistema de Controle Financeiro

Sistema web desenvolvido para auxiliar no controle financeiro da SPASB, permitindo o cadastro e acompanhamento de entradas, despesas e geração de relatórios.

## Objetivo

Desenvolver uma solução web para apoiar o controle financeiro da organização, facilitando o registro das movimentações e a geração de relatórios mensais.

## Tecnologias utilizadas

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap
- JavaScript
- Django REST Framework
- Git
- Nuvem
## Funcionalidades

- Cadastro de entradas
- Cadastro de despesas
- Edição e exclusão de registros
- Regras de divisão dos valores das entradas
- Relatório financeiro mensal
- Exportação de relatórios em PDF
- Exportação de relatórios em Excel
- API para consulta de entradas e despesas
- Validações de formulários
- Recursos de acessibilidade
- Testes automatizados
- Nuvem
